Carrier furnace fault codes

Two-digit status codes used on Carrier, Bryant and Payne gas furnaces.

Code lists differ between control boards. The chart on the inside of the furnace's blower door is the one that applies to that furnace; use this page as a guide to what the codes mean.

How to read the code

Look at the LED on the control board through the sight glass in the lower door. The code is two digits: the first digit is the number of short flashes, the second is the number of long flashes. Two short and four long is code 24. Read the code before removing the door or switching power off, because on many boards cutting power erases it.

  • LED on steady: the control has power and is working normally.
  • LED off: no power to the board. Check the breaker, the switch at the furnace and the door switch.
  • LED flashing rapidly: line voltage polarity is reversed, or the furnace is not grounded.

The three you will see most

Code 31: pressure switch

The inducer has to prove that the vent is drawing before the furnace is allowed to light. On condensing furnaces the usual causes are water in the pressure tubing, a blocked condensate trap, or ice, snow or a nest at the vent termination.

Code 33: limit circuit

The furnace is overheating or a safety switch is open. Start with the filter. If the filter is clean, check that the blower is running at the right speed and measure the temperature rise.

Code 34: ignition proving

If the burners light and then drop out after a few seconds, the flame sensor is not proving flame. A sensor coated with oxide is the usual cause and cleans up with a light abrasive pad. If the burners never light, look at the igniter and the gas supply.

If you smell gas, leave the building and call the gas utility. Repeatedly resetting a furnace that locks out on a safety is not a repair.
